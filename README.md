# Security Program

C# WPF PC 프로그램입니다.
보안 관리 업무를 지원할 수 있습니다.

## 주요 기능
- 파일 암호화 및 복호화
- 실시간 Windows Event Log 모니터링
- 비밀번호 강도 분석
- 로컬 네트워크 포트 스캔
- 보고서 생성 (PDF)


## 기술 스택
- C#, .NET 8, WPF
- Windows Event Log, TCP client
- iTextSharp for PDF generation

## English Overview

Security Program is a C#/.NET 8 WPF desktop application for practical security-management tasks.

### Key Features

- File encryption and decryption
- Real-time Windows Event Log monitoring
- Password strength analysis
- Local network port scanning
- PDF report generation

### Tech Stack

- C#, .NET 8, WPF
- Windows Event Log, TCP client
- iTextSharp

* 개인 포트폴리오 목적으로 작성했습니다.
